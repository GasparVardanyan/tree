# tree

A tiny header-only  example library for the Vix Registry demo.

## Usage
- Include headers from `include/`
- Basic example in `examples/basics/main.cpp`
- Example of extending trees to set and map in `examples/set_and_map/main.cpp`
- Example of binary tree node usage in expression trees in  `examples/expression_tree/main.cpp`
